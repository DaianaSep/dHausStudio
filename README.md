# D haus studio

Sitio web de D haus studio, especializado en fotografía inmobiliaria, planos 2D, video y tours virtuales.

## Contenido

- Servicios detallados para real estate
- Cotizador interactivo con zonas, servicios y logística
- Condiciones de reprogramación y retiro de llaves
- Página adaptable a celular y escritorio

## Vista local

Abrí `index.html` en un navegador. Antes de publicar, reemplazá el correo y el enlace de WhatsApp de ejemplo por los datos reales de D haus studio, y actualizá los valores de referencia de la calculadora en `index.html`.
